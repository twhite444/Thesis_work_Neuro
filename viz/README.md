# Visualization Outputs

This directory contains all visualization outputs generated by the pipeline.

## Directory Structure

```
viz/
├── molecules/          # Molecular visualizations
│   ├── CID_*.png      # Static molecular structure images
│   ├── CID_*.html     # Interactive 3D molecular viewers
│   └── gallery.png    # Gallery view of multiple molecules
│
├── maps/              # Activity map visualizations
│   ├── coverage_counts.png
│   ├── coverage_histogram.png
│   ├── global_mask.png
│   ├── masked_averaged_example.png
│   └── masked_averaged_gallery.png
│
└── reports/           # Analysis reports and figures
    └── (training metrics, comparisons, etc.)
```

## Files Are Auto-Generated

All files in this directory are automatically created by the pipeline. The directories are created automatically when needed, so you don't need to create them manually.

## Molecular Visualizations

### Static Images (PNG)
- **Simple mode**: Clean molecular structures
  - 2D: RDKit drawing
  - 3D: Ultra-high-quality PyMOL sphere rendering (2000×2000, ray traced)
- **Detailed mode**: Molecule + comprehensive graph information

Generated by: `load_graph_by_cid()` in `src/olfactory_modeling/data/molecular_graphs.py`

### Interactive Viewers (HTML)
- Interactive 3D viewers using py3Dmol
- Rotate, zoom, pan in browser
- Multiple rendering styles available

Generated by: `visualize_molecule_interactive()` in `src/olfactory_modeling/data/molecular_graphs.py`

## Activity Maps

Visualizations of olfactory activity patterns:
- **Coverage analysis**: Shows which pixels have data across all maps
- **Global mask**: Shows the region used for analysis
- **Averaged maps**: CID-averaged activity patterns
- **Galleries**: Multiple maps shown together

Generated by: `load_and_mask_maps()` in `src/olfactory_modeling/pipeline/activity_maps.py`

## Reports

Analysis figures, training metrics, and comparison plots will be saved here.

---

**Note**: This directory is typically excluded from version control (via `.gitignore`) since visualizations can be regenerated from the source data.
